ヘルプ

仕事の ながれ

クエストを書く → 勇者に任せる → 指示を送る → 報告と変更を見る → 採用する。 直したいときは やり直してもらおう。次の操作は クエストの札に出る。

町 / 勇者
プロジェクト / CLI の セッション
HP / MP / Lv
HP：最近の失敗の少なさ。MP：会話の残り（不明は？）。Lv：終えた仕事。品質の点数ではない。
クエスト / 鑑定（かんてい）/ 合格条件
クエスト：勇者が去っても残る仕事。 鑑定：git の変更を見る。 合格条件：npm test などの条件と、合格の証拠。採用を決めるのは あなた。

そうさ

  • 町や 勇者を クリック
  • コマンド：↑ ↓ ← → で えらぶ・Enter で きめる
  • Ctrl+Enter で つたえる
  • Esc で とじる
