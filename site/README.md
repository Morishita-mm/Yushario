# Yushario 紹介・ドキュメントサイト

「退屈な仕事を、冒険に。」を主題にした紹介、世界観、画面付きガイドと触れる体験版です。

## ローカル確認

リポジトリ直下で `npm run dev:web -- --host 127.0.0.1` を実行し、ViteのURLの `/site/` を開きます。開発用モックは `/mock.html`、サイトの体験版は `/site/demo.html` です。

## 公開

```sh
npm run build:site
```

生成される `site-dist/` を静的ホスティングへ配信してください。既存のViteを使い、追加依存はありません。サブディレクトリへも配信できます。`site/` のソースを直接アップロードしても、体験版のTypeScriptは実行できません。

絵、ロゴ、フォント、原寸スクリーンショット、ライセンスを同梱します。アプリ本体のローカルサーバーは公開しないでください。ChatGPT Sitesへの公開は未実施です。この環境には同サービスの公開連携がありません。

## 本番と共通の体験版

HTMLの共通元は `src/web/rpg/app.html`。Viteが本番、開発モック、公開体験版へ同じHTMLを差し込みます。`demo.js` は開発モックと同じ `src/web/art/mock.ts` を起動します。

モックは本番の `rpg/main.ts`・CSS・Scene・Status・会話・クエスト・鑑定をそのまま使い、HTTP／WSの応答だけをブラウザ内の架空データに置き換えます。本番用とモック用のサイドバーや開閉処理は別々に維持しません。

場面切替・勇者追加・状態変更のパネルはアプリの外側にあり、折り畳めます。クエスト追加ボタンは本番と同じ作成窓を開きます。アプリHTMLや操作を直すとモックにも反映されます。公開済みの体験版へ反映するには再ビルド・再配信が必要です。

実際のCLI・コマンド・Git・外部AIは実行しません。端末は案内を表示するだけ、依頼への返答はデモと明示した固定文です。未対応の操作はエラーで知らせ、成功したとは表示しません。データ変更はページ内のみで、再読み込みで戻ります。詳細は [docs/MOCK.md](../docs/MOCK.md) を参照してください。

## サイトのファイル

- `index.html`, `style.css`: 紹介、世界観、体験版への入口と埋め込み、クイックスタート、対応範囲、プライバシー、FAQ。
- `guide.css`: 番号付きの操作画像と手順。
- `main.js`: 町の紹介画像の切り替え、起動コマンドのコピー。
- `demo.html`, `demo.js`: 共通アプリと外側のモック操作パネルを読み込む入口。モック専用のアプリHTML・CSSは置かない。
- `../scripts/build-site.mjs`: 紹介と体験版をビルドし、素材を同梱。
- `LICENSE`, `NOTICE`: コードと既存素材のライセンス・通知。

## 撮影とプライバシー

素材は現在のworktreeのOrca内蔵ブラウザで撮影しました。本番セッションや利用者の実ターミナルは撮影していません。アドレスバー・認証URL・利用者のパス・会話・認証情報は掲載していません。

町・戦闘などの9枚は、共通化前の `/mock.html` のデモです。描画を確認後、Canvasの画素をPNGに書き出しました。画面付きガイドの8枚は操作箇所を切り抜いたスクリーンショットです。黄色い番号はサイトの注釈で、画像に架空のUIを描き足してはいません。静止画像は撮影時点のもので、本番の変更で自動更新されるのは触れる体験版です。

| ファイル | 撮影元 |
| --- | --- |
| world.png / town.png | 共通化前のデモのワールド / 草原の町 |
| port.png / snow.png / desert.png / volcano.png | 同デモの各町 |
| battle.png / inn.png / church.png | 同デモの戦闘 / 宿屋 / 教会 |

`logo.png` は `public/logo/title.png` の複製。`key-visual.png` は `battle.png` の上100pxから435pxぶんを切り抜き、ステータスとメッセージ欄を除いたものです。他社ゲームの素材や新しいイラストは追加していません。

`assets/fonts/` のDotGothic16は既存依存の `@fontsource/dotgothic16` から複製し、外部通信なしで配信します。同梱の `OFL.txt` がライセンスです。
